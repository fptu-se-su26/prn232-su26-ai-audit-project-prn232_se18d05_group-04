# VivuCar - UI Markdown Specs - Thành viên 5

Bộ file phác thảo UI cho Thành viên 5: Xử lý đơn hàng đối tác & Hỗ trợ.

## Phạm vi
- Người cho thuê xem và xử lý yêu cầu đặt xe.
- Xác nhận hoặc từ chối booking request.
- Quản lý bàn giao xe.
- Ghi nhận tình trạng xe khi bàn giao/trả xe.
- Xác nhận khách đã trả xe.
- Cập nhật trạng thái đơn hàng theo vòng đời chuyến đi.
- AI Chatbot hỗ trợ khách thuê.
- Lưu lịch sử hội thoại và live chat để người cho thuê tiếp quản.

## Nguyên tắc
- Chỉ dùng HTML, CSS, JavaScript thuần.
- Không dùng React, Vue, Angular.
- Không phụ thuộc Bootstrap.
- Mỗi trang/component là một file `.md`.
- Codex có thể đọc từng file để dựng UI tương ứng.
