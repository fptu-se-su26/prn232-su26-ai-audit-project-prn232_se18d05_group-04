# VivuCar - UI Markdown Specs - Thành viên 3

Bộ file phác thảo UI cho Thành viên 3: Luồng Đặt xe & Thanh toán.

## Phạm vi
- Booking checkout.
- Kiểm tra lịch trống và chống đặt trùng.
- Nhập thông tin người lái và upload hồ sơ.
- Tính phí động.
- Thanh toán tiền cọc.
- Theo dõi đơn đặt xe.
- Xem chi tiết đơn.
- Xuất hợp đồng thuê xe điện tử.
- Hủy đơn và giải phóng lịch xe.

## Nguyên tắc
- Chỉ dùng HTML, CSS, JavaScript thuần.
- Không dùng React, Vue, Angular.
- Không phụ thuộc Bootstrap.
- Mỗi trang/component là một file `.md`.
- Codex có thể đọc từng file để dựng UI tương ứng.
