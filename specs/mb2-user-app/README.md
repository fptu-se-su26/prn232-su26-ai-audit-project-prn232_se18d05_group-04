# VivuCar - UI Markdown Specs - Thành viên 2

Bộ file phác thảo UI cho phần Thành viên 2: Trải nghiệm Người dùng & Đặt chỗ.

## Phạm vi
- User App/Web dành cho khách hàng thuê xe.
- Tập trung vào luồng tìm xe, xem chi tiết, lọc xe, quản lý hồ sơ, upload giấy phép lái xe, đánh giá xe.

## Nguyên tắc
- Chỉ dùng HTML, CSS, JavaScript thuần.
- Không dùng React, Vue, Angular.
- Không phụ thuộc Bootstrap.
- Mỗi trang/component là một file `.md`.
- Codex có thể đọc từng file để dựng UI tương ứng.
