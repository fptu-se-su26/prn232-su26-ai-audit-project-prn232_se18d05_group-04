# VivuCar - UI Markdown Specs - Thành viên 4

Bộ file phác thảo UI cho Thành viên 4: Đăng kiểm tài sản & Sau chuyến đi.

## Phạm vi
- Quản lý trả xe.
- Kiểm tra tình trạng xe sau chuyến đi.
- Xác nhận hoàn tất chuyến đi.
- Đánh giá và phản hồi sau chuyến đi.
- Báo cáo sự cố sau chuyến đi.
- Người cho thuê đăng xe, cập nhật xe, quản lý hình ảnh xe.
- Cập nhật trạng thái, tạm ngưng/mở lại cho thuê.
- Theo dõi lịch sử hoạt động xe.

## Nguyên tắc
- Chỉ dùng HTML, CSS, JavaScript thuần.
- Không dùng React, Vue, Angular.
- Không phụ thuộc Bootstrap.
- Mỗi trang/component là một file `.md`.
- Codex có thể đọc từng file để dựng UI tương ứng.
